# 血包和火焰生成记录

生成日期：2026-10-04。使用内置 image_gen，没有安装插件或软件包。

参考图片为 myimg/普通敌人血包素材.png、精英敌人血包素材.png、BOSS血包素材.png，保留对应的微笑、眨眼吐舌、比心特征。参考文件保持原样。

三张生成图去除透明留白后，以最近邻方式放入 24×24 透明画布；火焰图集按 3 列×2 行顺序分成六帧，最近邻缩小为 32×32。保留不透明部分的颜色和 Alpha，完全透明像素清空 RGB，避免透明留白带入颜色。
图像整理使用 Windows 自带 .NET System.Drawing；动态预览使用已有 C:/Program Files/JianyingPro/Apps/5.7.0.11527/ffmpeg.exe。未新增软件安装。
