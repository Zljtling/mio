## 1. 研究背景与挑战

### 1.1 研究背景：为什么要做“组织形态 → 空间基因表达”的预测

论文的核心问题是：**能否直接从常规 H&E 染色病理图像中，预测组织局部区域的空间基因表达？**

背景逻辑可以概括为三层：

1. **传统转录组丢失空间信息**
   - bulk RNA-seq 或单细胞 RNA-seq 能测基因表达，但常规分析难以保留组织切片内的高分辨率空间异质性。
   - 论文指出，研究异质性时往往只能从组织多个区域采样，而不是在同一张切片内刻画细粒度空间变化。

2. **空间转录组技术提供了“带位置”的表达数据**
   - 空间转录组用 DNA barcode 标记组织切片中的不同 spot，再通过 RNA-seq 恢复每个 spot 内数十个细胞的表达。
   - 每个组织切片可得到数百个 spot 的表达向量。
   - 论文正文使用的数据：**23 名乳腺癌患者、68 张乳腺组织切片、30,612 个 spot**；每个 spot 直径约 **100 μm**，中心间距约 200 μm。
   - 对应 H&E 组织病理图像 readily available，并且可与 spot 对齐。Fig.1a 给出了从全切片图像取 patch、卷积网络、全连接层到 250 个基因表达预测的 workflow 示意。

3. **病理图像与分子表达之间存在可学习的形态—分子关联**
   - H&E 图像包含细胞核大小、密度、组织架构、肿瘤/正常区域等形态信息。
   - 论文希望用深度学习自动学习这些形态特征，并映射到局部基因表达。
   - 这比只用切片级标签做肿瘤分类、突变预测、亚型分类更细：目标是**每个小区域/spot 的细粒度表达预测**，而不是整张切片一个标签。

### 1.2 关键挑战

论文要解决的核心挑战包括：

1. **空间分辨率与输入窗口匹配问题**
   - ST spot 约 \(100 \times 100\ \mu m^2\)，但 ST-Net 输入是 **224×224 像素 patch**，对应约 \(150 \times 150\ \mu m^2\)，略大于 spot。
   - 需要让图像 patch 的接受野与 spot 表达标签对齐，同时保留局部形态信息。

2. **从图像预测多基因表达是多任务、高噪声回归问题**
   - 论文选择预测平均表达最高的 **250 个基因**。
   - 许多基因表达很低，信噪比低，难以预测。
   - 空间转录组本身有实验噪声和测序深度限制；论文提到中位 counts 为 3,426/spot（原始数据），10x 外部数据为 17,531/spot。
   - 因此模型既要学形态信号，也要在一定程度上“去噪”。

3. **跨患者泛化**
   - 不同患者、切片、染色、组织构成差异大。
   - 论文采用 **leave-one-patient-out cross validation**：每次用 22 名患者训练，在留出患者上预测。这检验的是对未见患者的泛化，而不是同一患者内插值。

4. **外部数据泛化**
   - 10x Genomics 乳腺癌数据来自不同设施、不同染色协议、更深测序。
   - ST-Net 不做任何修改或调参直接应用，检验跨数据集稳健性。
   - TCGA 数据更是不同机构、不同扫描、且测序组织与成像组织不完全相同，属于更强挑战。

5. **超越粗粒度肿瘤/正常标签**
   - 病理医生标注的 tumor/normal 标签只能解释部分基因差异。
   - 论文要证明 ST-Net 能捕捉**肿瘤内异质性**和更细粒度形态信息，而不是只学“肿瘤 vs 正常”。
   - Fig.2 展示了真实表达、预测表达、tumor/normal 标注，以及 ST-Net 与 baseline 的对比；Fig.3 用 integrated gradients 解释 FASN 高表达与 enlarged nuclei 相关；Fig.4 讨论 latent space 对 tumor/normal 的自然分离。

6. **与手工特征和细胞类型组成模型比较**
   - 传统方法可用细胞核大小、颜色、距离等手工特征，或估计细胞类型组成。
   - 论文需要证明 CNN 能捕捉比手工特征和细胞组成更复杂的形态信号。
   - 正文报告：ST-Net 在 250 个基因中，对 245 个基因的中位相关性高于 tumor/normal baseline；对 236 个基因高于手工特征随机森林；对 242 个基因高于细胞组成模型。

### 1.3 本阶段一句话总结

论文的背景是：**空间转录组提供了带空间位置的局部基因表达，H&E 图像普遍可得；挑战在于如何用深度学习把局部组织形态映射到多基因空间表达，并在未见患者、外部数据集和肿瘤内异质区域上仍然有效。** ST-Net 的目标不是整张切片分类，而是以约 100 μm 分辨率预测 spot 级 250 个基因的 log 归一化表达。

## 2. 方法架构与详细思路

### 2.1 总体任务定义

ST-Net 的任务不是“整张切片分类”，而是：

> 给定以某个空间转录组 spot 为中心的 H&E 图像 patch，预测该 spot 内 **250 个高表达基因**的归一化、log 变换后的表达值。

论文正文中的数据规模：
- 23 名乳腺癌患者；
- 68 张乳腺组织切片；
- 30,612 个 spot；
- 每个 spot 直径约 \(100\ \mu m\)；
- 输入 patch 为 \(224\times224\) 像素，对应约 \(150\times150\ \mu m^2\)，略大于 spot；
- 输出为 250 维表达向量。

这个任务可以看作**多任务回归**：每个基因是一个回归任务，所有基因共享卷积特征，最后一层为每个基因分别输出预测值。

---

### 2.2 数据与标签构造流程

对应 **Fig.1a** 的 workflow：

1. **全切片 H&E 图像**
   - 整张病理图像非常大，接近 \(10,000\times10,000\) 像素，不能直接输入 CNN。
   - 因此以每个空间转录组 spot 为中心，从全切片图像中裁剪 \(224\times224\) 像素 patch。

2. **空间转录组标签**
   - 每个 spot 有 RNA-seq 得到的基因计数向量。
   - 论文选择平均表达最高的 250 个基因作为预测目标。
   - 原始计数经过归一化和 log 变换后作为回归标签。

3. **CNN 前向传播**
   - patch 输入 DenseNet-121；
   - 卷积层共享权重，提取形态特征；
   - 得到 1,024 维表示；
   - 最后接一个全连接层，输出 250 个基因的预测值。

4. **预测输出**
   - 输出向量对应 250 个基因的 log 归一化表达预测；
   - 与真实标签计算误差并训练。

**Fig.1b** 展示了每位患者采样的 spot 数量；**Fig.1c** 展示每个 spot 中非零计数基因数分布；**Fig.1d** 展示每个 spot 捕获的 reads 总数分布。这些图说明数据具有明显的测序深度和稀疏性差异，也是后续需要归一化和平滑评估的原因。

---

### 2.3 输入 patch 与网络架构

#### 2.3.1 输入

- 输入尺寸：\(224\times224\) 像素；
- 放大倍数：\(\times20\)；
- patch 中心对齐到空间转录组 spot；
- 对应物理尺寸约 \(150\times150\ \mu m^2\)；
- 比 spot 的 \(100\times100\ \mu m^2\) 稍大，目的是让网络看到 spot 周围上下文。

#### 2.3.2 主干网络：DenseNet-121

论文使用 **DenseNet-121**，并加载 **ImageNet 预训练权重**。

架构要点：
- 120 个卷积层；
- 所有卷积层在 250 个基因任务之间**共享权重**；
- 卷积部分后得到 **1,024 维表示**；
- 最后接一个全连接层；
- 全连接层对每个基因使用**不共享权重**，输出 250 个基因预测。

这样设计的思路是：
- 共享卷积层：学习通用的组织形态特征，节省计算，并让不同基因任务共享表示；
- 不共享输出层：每个基因有独立的回归头，适应不同基因的表达尺度与模式；
- 多任务学习：250 个基因同时训练，相当于共享形态表示的多输出回归。

对应 **Fig.1a** 中：
- “Convolutions (shared)” → “1,024-dim representation” → “Fully connected layer (250 outputs)” → “Predictions for 250 genes”。

---

### 2.4 标签预处理：归一化与 log 变换

论文对每个 spot 的基因计数做了两步变换：

1. **加伪计数并归一化总表达**
   - 目的：不同 spot 的细胞密度和测序深度不同，总表达量高不一定代表某基因相对表达高。
   - 加伪计数 1 是为了避免后续 log 出现零。
   - 归一化总表达后，细胞密度不能被模型直接利用，从而迫使模型学习形态相关信号。

2. **取 log**
   - 基因计数高度偏斜；
   - log 变换把值带到更合理范围，减小极端值影响。

#### 公式含义表

| 符号/公式                                                    | 含义                                       |
| ------------------------------------------------------------ | ------------------------------------------ |
| \(c_{s,g}\)                                                  | spot \(s\) 中基因 \(g\) 的原始计数         |
| \(\tilde c_{s,g}=c_{s,g}+1\)                                 | 加伪计数 1，避免 log 零问题                |
| \(n_{s,g}=\dfrac{\tilde c_{s,g}}{\sum_{g'}\tilde c_{s,g'}}\) | 对 spot 内总表达归一化                     |
| \(y_{s,g}=\log(n_{s,g})\)                                    | log 变换后的回归标签                       |
| \(G_{250}\)                                                  | 平均表达最高的 250 个基因集合              |
| \(\hat y_{s,g}\)                                             | ST-Net 对 spot \(s\) 中基因 \(g\) 的预测值 |

> 注：论文正文描述为“加伪计数 1 后归一化总表达，再取 log”。上表是按正文含义的规范化表达。

---

### 2.5 损失函数与训练目标

ST-Net 被训练为对每个基因最小化平方误差。整体损失可写为：

\[
L=\sum_{s}\sum_{g\in G_{250}}\left(y_{s,g}-\hat y_{s,g}\right)^2
\]

#### 公式含义表

| 符号/公式                               | 含义                |
| --------------------------------------- | ------------------- |
| \(L\)                                   | 训练损失            |
| \(s\)                                   | 一个训练 spot/patch |
| \(g\)                                   | 一个目标基因        |
| \(G_{250}\)                             | 250 个目标基因集合  |
| \(y_{s,g}\)                             | 真实 log 归一化表达 |
| \(\hat y_{s,g}\)                        | 模型预测表达        |
| \(\left(y_{s,g}-\hat y_{s,g}\right)^2\) | 平方误差            |

论文正文说“trained ST-Net to minimize the squared error for each of the genes”，因此这是多输出平方误差回归。

---

### 2.6 训练策略与防止过拟合

#### 2.6.1 留一患者交叉验证

为了检验对未见患者的泛化，论文所有结果使用 **leave-one-patient-out cross validation**：

- 每次用 22 名患者训练；
- 在剩余 1 名患者上测试；
- 重复 23 次，每次留出不同患者；
- 结果在留出患者上汇总。

这一点很关键：它不是同一患者内随机划分 spot，而是**跨患者泛化**。

#### 2.6.2 训练超参数

正文给出的训练设置：
- 初始化：ImageNet 预训练权重；
- 优化器：随机梯度下降 SGD；
- 学习率：\(10^{-6}\)；
- momentum：0.9；
- 最多 50 epochs；
- batch size：32；
- 在 22 名训练患者内部再做 4 折交叉验证选择 epoch 数。

#### 2.6.3 数据增强与测试时平均

训练时：
- 随机旋转 0、90、180、270 度；
- 50% 概率做镜像。

测试时：
- 对旋转和反射产生的 8 种对称变换分别预测；
- 取平均作为最终预测。

这相当于测试时集成，降低单次前向传播的方差。

---

### 2.7 评估指标与“患者一致数”

论文使用多种指标：

1. **RMSE**
   - 预测 log 表达与真实 log 表达的均方根误差；
   - 正文报告 RMSE 为 0.31，对应平均约 1.4 倍误差范围。

2. **Pearson 相关**
   - 对每个基因、每个切片/患者计算预测与观测的 Pearson 相关；
   - 用于衡量空间变化趋势是否一致。

3. **患者一致数**
   - 对每个基因，统计 23 名患者中有多少名患者的预测与真实表达呈正相关；
   - 正文以“在 20 个或更多患者中正相关”结合 FDR 0.05 作为可预测基因标准；
   - 最终得到 102 个基因。

4. **AUROC**
   - 用于判断模型能否区分某基因高表达 spot 与低表达 spot；
   - 正文定义高表达为 top 25% spots，低表达为 bottom 25% spots；
   - 10x 外部验证中，平均 AUROC 为 0.73。

5. **FDR 与多重检验校正**
   - 每个基因是一个假设；
   - 使用 Holm–Bonferroni 方法校正多重假设检验；
   - 正文报告 FDR 0.05 下的可预测基因数。

#### 公式含义表

| 指标/符号     | 含义                                                  |
| ------------- | ----------------------------------------------------- |
| RMSE          | \(\sqrt{\frac{1}{N}\sum (y-\hat y)^2}\)，衡量整体误差 |
| Pearson \(r\) | 预测表达与真实表达的线性相关                          |
| 患者一致数    | 23 名患者中预测与真实正相关的患者数量                 |
| AUROC         | 区分高表达 spot 与低表达 spot 的曲线下面积            |
| FDR           | 多重检验校正后的错误发现率                            |

---

### 2.8 平滑表达评估：降低空间转录组噪声

空间转录组存在实验噪声和测序深度限制。论文在评估时构造了“平滑表达”：

- 对每个 spot，取其相邻 spot 的平均表达；
- 相当于 3×3 邻域平均，中心为当前 spot；
- 这模拟在更大区域、更深测序下的表达测量。

然后比较 ST-Net 预测与平滑表达的一致性。正文报告预测与平滑实验数据的一致性更好，说明模型学到了一定的去噪能力。**Table 1** 中列出了 top 5 基因的 median correlation 与 median correlation (smooth)，例如 GNAS、ACTG1、FASN、DDX5、XBP1 的平滑后相关性更高。

---

### 2.9 外部验证方法：10x Genomics 与 TCGA

#### 2.9.1 10x Genomics 外部验证

- 数据：10x Genomics 乳腺癌空间基因表达数据；
- 两张力切片，浸润性导管癌；
- 测序更深，中位 17,531 counts/spot；
- 包含 250 个目标基因中的 234 个；
- ST-Net **不做任何修改或调参**直接应用；
- 结果：234 个基因中 207 个预测与实验正相关；平均 Pearson 0.33；平均 AUROC 0.73。

这检验跨设施、跨染色协议、跨测序深度的泛化。

#### 2.9.2 TCGA 应用

TCGA 只有 bulk RNA-seq，没有空间转录组。论文做法：

1. 对 TCGA 乳腺癌 H&E 全切片图像分块：
   - 使用 \(512\times512\) 像素非重叠窗口；
   - 去除大部分为背景的 patch；
   - 背景判定：像素平均 RGB ≤ 220 视为接近白色；
   - 若一个 patch 超过 50% 像素为背景，则移除。

2. 用训练好的 ST-Net 直接预测每个 patch 的 250 个基因空间表达，不重新训练。

3. 将同一张切片的 patch 预测取平均，得到 **pseudo-bulk** 表达：
   \[
   \bar y_{p,g}=\frac{1}{|P_p|}\sum_{i\in P_p}\hat y_{i,g}
   \]
   其中 \(P_p\) 是患者/切片 \(p\) 的 patch 集合。

4. 将 pseudo-bulk 与 TCGA bulk RNA-seq 做相关：
   - 249 个基因中 177 个正相关；
   - 55 个基因显著正相关，FDR 0.05；
   - 没有显著负相关基因。

5. 亚型区分：
   - 用 ST-Net pseudo-bulk 做逻辑回归区分浸润性导管癌与浸润性小叶癌；
   - AUROC 0.83；
   - 与真实 TCGA bulk RNA-seq 的 AUROC 0.83 接近；
   - 略高于直接从 TCGA H&E 图像预测亚型的 AUROC 0.81。

#### 公式含义表

| 符号/公式        | 含义                                                         |
| ---------------- | ------------------------------------------------------------ |
| \(P_p\)          | 样本/患者 \(p\) 的 patch 集合                                |
| \(\bar y_{p,g}\) | ST-Net 预测在样本 \(p\) 上对基因 \(g\) 的 pseudo-bulk 平均值 |
| \(\hat y_{i,g}\) | patch \(i\) 中基因 \(g\) 的预测表达                          |
| AUROC 0.83       | 区分两种组织学亚型的性能                                     |

### 2.10 与 baseline 的比较思路

论文比较了三类方法：

1. **病理医生 tumor/normal 标签 baseline**
   - 每个 spot 用 tumor/normal 标签；
   - 若是 tumor，则预测其他患者 tumor 区域该基因平均表达；
   - 若是 normal，则预测其他患者 normal 区域平均表达。
   - 结果：baseline 在 35 个基因上达到 20/23 患者正相关；ST-Net 对 250 个基因中的 245 个有更高中位相关。
   - 对应 **Fig.2d**：散点图比较 ST-Net correlation 与 tumor/normal correlation，多数点位于对角线上方。

2. **手工细胞核特征 + 随机森林**
   - 用 HistomicsTK 提取每个细胞核的 10 个特征：
     - 大小 4 个：面积、长轴、短轴、长短轴比；
     - 颜色 3 个：红、绿、蓝通道均值；
     - 距离 3 个：到相邻细胞核的最大、平均、最小距离。
   - patch 级再计算均值、标准差、偏度、峰度及 10-bin 直方图。
   - 随机森林预测基因表达。
   - 结果：手工特征在 79 个基因上达到 20/23 患者正相关；ST-Net 对 236/250 个基因中位相关更高。

3. **细胞类型组成模型**
   - 对表达数据做非负矩阵分解 NMF，用 10 个因子表示细胞类型；
   - 训练 DenseNet-121 预测每个 patch 的细胞类型组成；
   - 再用 NMF 映射到基因表达。
   - 结果：该模型在 55 个基因上达到 20/23 患者正相关；ST-Net 对 242/250 个基因相关更高，平均相关提升 0.03。
   - 说明 ST-Net 捕捉了细胞类型组成之外的信息。

### 2.11 模型解释：integrated gradients 与 latent space

#### 2.11.1 Integrated gradients

**Fig.3** 展示三个 patch 及 ST-Net 对 FASN 高表达的归因区域：
- 红色高亮区域是 integrated gradients 认为对预测 FASN 高表达重要的区域；
- 这些区域对应 enlarged nuclei；
- FASN 在乳腺癌中过表达，是预后指标；
- 说明 ST-Net 学到“ enlarged nuclei 与高 FASN 表达相关”的形态线索。

#### 2.11.2 Latent space

- 取 ST-Net 最后的人工神经元层作为每个 spot 的 1,024 维 latent representation；
- 用 UMAP 可视化；
- 虽然训练从未使用病理医生 tumor/normal 标签，latent space 仍自然分离肿瘤与正常 spot；
- 对 latent features 做 k-means 两聚类，平均 purity 0.89，标准差 0.07；
- 说明网络学到的表示具有组织语义；
- 还发现 latent space 中最近邻不一定是物理相邻 spot，说明语义距离不同于物理距离。

对应 **Fig.4** 的 latent space 可视化。

---

### 2.12 方法架构一句话总结

ST-Net 的架构是：**以 spot 为中心的 224×224 H&E patch → DenseNet-121 共享卷积特征 → 1,024 维表示 → 250 输出全连接层 → 多基因平方误差回归**；训练采用 ImageNet 预训练、SGD、旋转/镜像增强和留一患者交叉验证；评估采用 RMSE、Pearson、患者一致数、AUROC、FDR，并通过平滑表达、10x 外部数据、TCGA pseudo-bulk、baseline 比较、integrated gradients 和 latent space 分析验证其有效性与可解释性。

## 3. 性能验证

### 3.1 验证框架：留一患者交叉验证

论文所有主要结果都采用 **leave-one-patient-out cross validation**：

- 每次用 22 名患者训练；
- 在剩余 1 名患者上测试；
- 迭代 23 次，每次留出不同患者；
- 最终在留出患者上汇总预测性能。

这检验的是**跨患者泛化**，而不是同一患者内部随机划分 spot 的插值能力。对空间转录组这种患者间组织构成、染色、测序深度差异较大的数据，这是更严格的验证方式。

---

### 3.2 内部验证：整体误差与可预测基因数

#### 3.2.1 RMSE

论文报告 ST-Net 预测的 log 表达与真实 log 表达的 **RMSE 为 0.31**，对应平均预测误差约在 **1.4 倍**范围内。

#### 3.2.2 可预测基因数

论文定义可预测基因为：

- 在 23 名患者中，至少有 **20 名患者**的预测表达与实验测量呈正相关；
- 对应 **FDR 0.05**。

结果：

> 250 个目标基因中，有 **102 个基因**满足该标准。

这说明相当一部分基因的表达水平可以从组织形态中预测出来。

#### 3.2.3 通路富集

用 DAVID 做通路分析发现，这 102 个基因中许多涉及：

- cancer pathways：37 个；
- pharmacogenomic pathways：35 个；
- immune pathways：31 个。

而剩余 148 个基因中，对应通路分别只有 11、14、9 个。说明 ST-Net 的预测能力在乳腺癌相关基因上富集。

#### 3.2.4 最优预测基因

**Table 1** 列出中位相关性最高的五个基因：

| 基因  | 一致患者数 | 中位相关 | 平滑后中位相关 | 10x 相关 |
| ----- | ---------: | -------: | -------------: | -------: |
| GNAS  |         23 |     0.34 |           0.49 |     0.43 |
| ACTG1 |         22 |     0.33 |           0.50 |     0.47 |
| FASN  |         23 |     0.31 |           0.50 |     0.46 |
| DDX5  |         22 |     0.30 |           0.52 |     0.51 |
| XBP1  |         21 |     0.29 |           0.43 |     0.54 |

其中 GNAS、FASN、DDX5、XBP1 是已知癌症生物标志物；ACTG1 编码 γ-actin，与细胞骨架相关。表中还显示，平滑实验数据后相关性普遍提高，说明模型学到了一定的去噪能力。

### 3.3 空间预测可视化：Fig.2a

**Fig.2a** 展示两个代表性组织切片：

- 第一列：H&E 图像；
- 第二列：病理医生标注的 tumor/normal；
- 第三列：真实 FASN 表达；
- 第四列：ST-Net 预测的 FASN 表达。

从图中可以看到：

- 颜色条为 z-score，范围约 -3 到 3。

这直观说明 ST-Net 能重建 spot 级空间表达模式。

### 3.4 平滑表达评估：降低实验噪声

空间转录组存在实验噪声和测序深度限制。论文通过“平滑表达”评估模型去噪能力：

- 对每个 spot，取其相邻 spot 的平均表达；
- 即 3×3 邻域平均，中心为当前 spot；
- 模拟更大区域、更深测序下的表达测量。

结果显示：
- ST-Net 预测与平滑实验数据的一致性更高；
- **Table 1** 中五个最优基因的平滑后中位相关从约 0.29–0.34 提升到 0.43–0.52；
- 说明模型预测捕捉的是区域性表达趋势，而非纯噪声。

**Fig.2b** 展示每个基因在平滑数据下被正确预测的患者数。不同曲线对应：
- ST-Net；
- tumor/normal baseline；
- 手工特征；
- Null。

图中 ST-Net 曲线总体最高，说明在更多基因上达到更多患者一致。

### 3.5 外部验证一：10x Genomics 乳腺癌数据

#### 3.5.1 验证设置

10x Genomics 数据：
- 两张力切片，浸润性导管癌；
- 测序更深，中位 17,531 counts/spot；
- 原始数据中位 3,426 counts/spot；
- 扫描倍率 ×20；
- 包含 ST-Net 250 个目标基因中的 234 个；
- ST-Net **不做任何修改或调参**直接应用。

这是跨设施、跨染色协议、跨测序深度的独立外部测试。

#### 3.5.2 结果

- 234 个基因中，**207 个基因**的预测与实验测量正相关；
- 全部 234 个基因平均 Pearson 相关为 **0.33**；
- 判断基因高/低表达的 **平均 AUROC 为 0.73**。

#### 3.5.3 Fig.2c 与 Fig.2d

- **Fig.2c**：AUROC 分布直方图，横轴 AUROC，纵轴基因数；大部分基因 AUROC 接近 0.7–0.9，说明预测高/低表达 spot 的能力较强。
- **Fig.2d**：ST-Net correlation 与 tumor/normal correlation 的散点图；多数点位于对角线上方，说明 ST-Net 的中位相关优于 tumor/normal baseline。

---

### 3.6 外部验证二：TCGA 乳腺癌数据

#### 3.6.1 验证设置

TCGA 数据与原始数据差异很大：
- 不同机构采集和扫描；
- 技术流程不同；
- 测序组织与成像组织不完全相同；
- TCGA 只有 bulk RNA-seq，没有空间转录组。

论文用训练好的 ST-Net 直接预测 TCGA H&E 图像，不重新训练：
- 1,550 张 TCGA 乳腺肿瘤切片；
- 来自 1,093 名患者；
- 对每张图像分块预测；
- 将同一张切片的 patch 预测取平均，得到 pseudo-bulk 表达。

#### 3.6.2 pseudo-bulk 公式

\[
\bar y_{p,g}=\frac{1}{|P_p|}\sum_{i\in P_p}\hat y_{i,g}
\]

#### 公式含义表

| 符号/公式        | 含义                                        |
| ---------------- | ------------------------------------------- |
| \(p\)            | 一个 TCGA 样本/切片                         |
| \(P_p\)          | 样本 \(p\) 的 patch 集合                    |
| \(i\)            | 一个 patch                                  |
| \(g\)            | 一个基因                                    |
| \(\hat y_{i,g}\) | ST-Net 对 patch \(i\) 中基因 \(g\) 的预测   |
| \(\bar y_{p,g}\) | 样本 \(p\) 中基因 \(g\) 的 pseudo-bulk 预测 |

#### 3.6.3 结果

- 249 个可比基因中，**177 个基因**的 ST-Net pseudo-bulk 与 TCGA bulk RNA-seq 正相关；
- **55 个基因**显著正相关，FDR 0.05；
- **没有基因**显著负相关。

亚型区分结果：
- 用 ST-Net pseudo-bulk 区分浸润性导管癌与浸润性小叶癌，AUROC **0.83**；
- 用真实 TCGA bulk RNA-seq，AUROC 也为 **0.83**；
- 直接从 TCGA H&E 图像预测亚型，AUROC **0.81**。

说明 ST-Net 在跨机构、跨数据类型的 TCGA 上仍能提供有意义的分子信息。

---

### 3.7 肿瘤与免疫表达的空间共定位

论文利用 55 个与 TCGA bulk 显著正相关的基因，选择：
- 3 个肿瘤生长标志基因：AEBP1、BGN、P4HB；
- 3 个免疫激活标志基因：PABPC1、TAGLN2、HLA-B。

然后计算肿瘤与免疫表达谱的空间相关性，分别在：
- 原始 ST-Net 数据；
- TCGA 上由 ST-Net 预测的空间表达。

结果：
- 在 TCGA 和原始数据中，肿瘤与免疫基因倾向于**比随机预期更少共定位**；
- \(P<0.001\)；
- 这与“约 75% 乳腺癌患者肿瘤浸润淋巴细胞比例低”的已有发现一致。

说明 ST-Net 可以从 H&E 图像推断肿瘤—免疫空间关系，可能成为候选生物标志物。

---

### 3.8 肿瘤内异质性验证

论文按病理医生 tumor/normal 标注分层，分别看：
- 仅肿瘤区域内的表达变化；
- 仅正常区域内的表达变化。

结果：
- 在肿瘤-only 组织中，**63 个基因**在 23 名患者中至少 20 名被正确预测，FDR 0.05；
- 在正常-only 组织中，**27 个基因**在 21 名有正常组织的患者中至少 18 名被正确预测，FDR 0.06。

这说明 ST-Net 不只是在区分 tumor/normal，而能在同一类组织内部预测表达变化。

肿瘤内变异最高的五个基因是：
- GNAS、FASN、AEBP1、SPARC、BGN；
- 均为已知癌症生物标志物；
- AEBP1 高表达与更小细胞核、更低核密度相关（\(P<0.01\)）；
- SPARC 与巨噬细胞相关；
- BGN 影响肿瘤细胞迁移和形态。

---

### 3.9 与 baseline 的比较

#### 3.9.1 tumor/normal 标签 baseline

做法：
- 若 spot 为 tumor，预测其他患者 tumor 区域该基因平均表达；
- 若 spot 为 normal，预测其他患者 normal 区域平均表达；
- 不使用图像细节。

结果：
- baseline 在 35 个基因上达到 20/23 患者正相关；
- ST-Net 对 250 个基因中的 **245 个**有更高中位相关；
- 对应 **Fig.2d**，多数点在对角线上方。

说明 ST-Net 捕捉到比 tumor/normal 分类更细的形态信息。

#### 3.9.2 手工细胞核特征 + 随机森林

手工特征包括：
- 大小 4 个：面积、长轴、短轴、长短轴比；
- 颜色 3 个：红、绿、蓝通道均值；
- 距离 3 个：到相邻核的最大、平均、最小距离；
- patch 级再计算均值、标准差、偏度、峰度和 10-bin 直方图。

结果：
- 手工特征在 79 个基因上达到 20/23 患者正相关；
- ST-Net 对 **236/250 个基因**的中位相关更高。

说明 CNN 学到的手工特征之外的复杂形态信号。

#### 3.9.3 细胞类型组成模型

做法：
- 对表达数据做 NMF，用 10 个因子表示细胞类型；
- 训练 DenseNet-121 预测每个 patch 的细胞类型组成；
- 再映射到基因表达。

结果：
- 细胞组成模型在 55 个基因上达到 20/23 患者正相关；
- ST-Net 对 **242/250 个基因**相关更高；
- 平均相关提升 **0.03**。

说明 ST-Net 捕捉了细胞类型组成之外的信息。

---

### 3.10 模型解释性验证：Fig.3 与 Fig.4

#### 3.10.1 Integrated gradients：Fig.3

**Fig.3** 展示三个 patch 以及 ST-Net 对 FASN 高表达的归因区域：
- 红色高亮区域是 integrated gradients 认为对预测 FASN 高表达重要的区域；
- 这些区域对应 enlarged nuclei；
- FASN 是乳腺癌中过表达、具有预后意义的基因；
- 说明 ST-Net 学到“ enlarged nuclei 与高 FASN 表达相关”的形态线索。

此外，正文还指出：
- 增大、拉长较少的细胞核通常对应更高表达水平；
- 这提供了形态—表达关系的可解释性。

#### 3.10.2 Latent space：Fig.4

ST-Net 最后的人工神经元层给出每个 spot 的 **1,024 维 latent representation**。

分析结果：
- 用 UMAP 可视化，latent space 自然分离 tumor 与 normal spot；
- 虽然训练从未使用病理医生 tumor/normal 标签；
- 对 latent features 做 k-means 两聚类，平均 purity **0.89**，标准差 0.07；
- 说明每个聚类主要包含肿瘤或正常区域；
- 代表性肿瘤 patch、非典型肿瘤 patch、代表性正常 patch、非典型正常 patch 显示非典型 patch 多为边界或模糊区域，可能提示标注问题；
- latent space 中最近邻不一定是物理相邻 spot，说明语义距离不同于物理距离。

### 3.11 性能验证一句话总结

ST-Net 在留一患者验证中取得 RMSE 0.31，并能从 250 个基因中可重复预测 102 个基因；在 10x 外部数据上无需调参即可对 234 个基因中的 207 个正相关，平均 AUROC 0.73；在 TCGA 上 pseudo-bulk 与 bulk RNA-seq 显著正相关，并能以 AUROC 0.83 区分组织学亚型；同时优于 tumor/normal baseline、手工细胞核特征和细胞类型组成模型，并能捕捉肿瘤内异质性与肿瘤—免疫空间关系。Fig.3 和 Fig.4 进一步说明模型关注 enlarged nuclei 等形态线索，且 latent space 自然编码组织语义。

## 4. 未来与展望

### 4.1 论文对自身工作的定位：proof-of-concept

论文将 ST-Net 定位为一个**概念验证性研究**：

- 证明空间转录组与深度学习的结合，可以从常规 H&E 病理图像预测局部基因表达；
- 证明这种预测在留出患者上有效；
- 证明模型可迁移到独立 10x Genomics 数据而无需修改；
- 证明模型能捕捉肿瘤内表达异质性，而不仅是 tumor/normal 粗分类。

因此，ST-Net 的意义不只是“预测 250 个基因”，而是展示了一条技术路线：

> **组织形态图像 → 深度学习表示 → 空间分子表达推断 → 空间生物标志物筛查**

---

### 4.2 框架可推广到其他组织类型

论文明确指出：

> 虽然本文聚焦乳腺肿瘤，但 ST-Net 的技术框架可以广泛推广到其他组织类型。

这意味着：
- 输入仍是 H&E patch；
- 输出仍是 spot 级多基因表达；
- 只要具备空间转录组标签和对应组织图像，就可以训练类似模型；
- 不同组织可替换目标基因集合和训练数据。

未来可扩展到：
- 其他癌种；
- 正常组织与发育组织；
- 免疫组织；
- 神经组织等具有空间异质性的组织。

---

### 4.3 数据规模与标准化将进一步提升性能

论文指出：

> 随着更多空间表达数据集产生、样本制备更加标准化，ST-Net 的性能预计会进一步提升。

原因包括：
- 当前研究只有 23 名患者，虽然 spot 数达 30,612，但患者数相对有限；
- 空间转录组存在实验噪声和测序深度限制；
- 不同数据集、染色协议、扫描设施存在技术差异；
- 更标准化的样本制备可减少批次效应；
- 更多训练数据可提升跨患者、跨机构泛化。

未来方向包括：
- 扩大患者队列；
- 增加组织类型；
- 统一染色、扫描和测序流程；
- 使用更深测序数据作为标签；
- 利用多中心数据训练更稳健的模型。

---

### 4.4 模型可学习额外结构：自动分离组织类型与发现标注异常

论文指出 ST-Net 除了预测表达，还学到了额外结构：

1. **自动分离 tumor 与 normal**
   - **Fig.4** 的 latent space 显示，虽然训练从未使用病理医生 tumor/normal 标签，latent representation 仍自然分离肿瘤与正常 spot；
   - k-means 两聚类平均 purity 0.89；
   - 说明模型表示具有组织语义。

2. **识别病理标注可能不一致的 patch**
   - 论文发现非典型 tumor/normal patch 多为模糊区域或肿瘤—正常边界；
   - 这可能提示潜在误标注；
   - 说明自动化方法可帮助发现细微生物信号和标注问题。

未来可发展：
- 用 ST-Net latent space 辅助病理标注质量控制；
- 自动发现边界区域、混合区域和异常区域；
- 将模型解释用于病理学家复核。

---

### 4.5 应用于大型组织学图像库：TCGA 的启示

论文强调：

> ST-Net 可以不做任何修改直接在 TCGA H&E 图像上预测，尽管数据存在显著差异。

这打开了应用大门：
- 大型历史组织学图像库通常只有 H&E 图像和有限分子数据；
- ST-Net 可从图像推断空间分子信息；
- 可用于推断肿瘤—免疫相互作用等重要分子标志物；
- TCGA 实验中，ST-Net pseudo-bulk 与 bulk RNA-seq 显著正相关，并能以 AUROC 0.83 区分组织学亚型。

未来方向：
- 将 ST-Net 应用于更多公共病理图像库；
- 从图像推断空间变异分子标志物；
- 结合临床随访数据，评估预测表达与预后、治疗反应的关系；
- 将图像推断的分子特征用于回顾性队列研究。

---

### 4.6 与单细胞 RNA-seq 的整合

论文指出空间转录组与单细胞 RNA-seq 捕获互补信息：

- **空间转录组**：保留位置，但分辨率约 100 μm，不是单细胞分辨率；
- **scRNA-seq**：测单细胞转录组，测序更深，但丢失空间位置。

未来整合方向：
1. **用 scRNA-seq 辅助空间数据解卷积**
   - 估计每个空间 spot 的细胞类型组成；
   - 帮助理解 ST-Net 预测背后的细胞来源。

2. **用 scRNA-seq 插补空间探针遗漏的基因**
   - 空间转录组可能漏检某些基因；
   - scRNA-seq 可提供更完整的基因表达参考；
   - 结合两者可推断空间数据中未直接测量的基因。

3. **多模态联合建模**
   - 图像形态；
   - 空间表达；
   - 单细胞表达；
   - 三者结合可能提升预测和解释能力。

---

### 4.7 更高分辨率与更细粒度空间异质性

当前 ST-Net 的分辨率约为 **100 μm**，对应一个 spot，而非单细胞。

论文指出：
- ST-Net 能捕捉肿瘤内异质性；
- 能在 tumor-only 和 normal-only 组织内预测表达变化；
- 但空间分辨率仍受 spot 大小限制。

未来可能方向：
- 结合更高分辨率空间技术；
- 结合单细胞分辨率方法；
- 提升模型从图像推断更细空间结构的能力；
- 研究复杂细胞间相互作用和微环境变异。

---

### 4.8 临床转化潜力：基于图像的空间分子标志物筛查

论文提出：

> 直接预测组织空间转录组可能实现基于图像的空间变异分子标志物筛查。

潜在临床应用包括：
- 从常规 H&E 图像推断关键癌症相关基因空间表达；
- 评估肿瘤—免疫空间关系；
- 识别肿瘤内异质性区域；
- 辅助筛选需要分子检测的区域；
- 在缺乏空间转录组检测的条件下提供分子线索；
- 将图像推断的分子特征与病理形态结合，用于诊断或预后研究。

但论文也明确这是 proof-of-concept，距离临床常规应用仍需：
- 更大规模验证；
- 多中心数据测试；
- 临床终点关联；
- 标准化与监管评估。

### 4.9 当前局限与未来改进方向

根据正文可归纳以下局限：

1. **患者数量有限**
   - 23 名患者；
   - 虽然 spot 数多，但患者间泛化仍需更大队列验证。

2. **只预测 250 个高表达基因**
   - 低表达基因信噪比低，难以预测；
   - 未来可结合更深测序、单细胞参考或更复杂模型扩展基因范围。

3. **空间分辨率约 100 μm**
   - 不是单细胞分辨率；
   - 一个 spot 包含多个细胞；
   - 未来需更高分辨率技术或多模态解卷积。

4. **实验噪声与测序深度限制**
   - 论文通过平滑评估说明模型有一定去噪能力；
   - 但标签噪声仍限制性能上限。

5. **外部验证仍有限**
   - 10x 数据只有 234 个可比基因；
   - TCGA 只有 bulk RNA-seq，只能用 pseudo-bulk 验证；
   - 未来需要更多独立空间转录组数据集。

6. **技术差异**
   - 不同设施、染色协议、扫描条件会引入变异；
   - 标准化和域适应可能是未来方向。

### 4.10 第四阶段一句话总结

ST-Net 展示了“H&E 图像直接推断空间基因表达”的可行性；未来方向包括推广到其他组织类型、扩大并标准化空间转录组数据、与 scRNA-seq 整合、提升空间分辨率、利用 latent space 发现标注异常、将模型应用于 TCGA 等大型病理图像库，并探索基于图像的空间分子标志物临床筛查。论文将其定位为 proof-of-concept，强调随着数据规模、标准化和分辨率提升，这类方法有望进一步发展和转化。
