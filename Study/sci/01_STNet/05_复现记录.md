数据来自作者指定的 [Mendeley 第 5 版](https://data.mendeley.com/datasets/29ntw7sh4r/5)，许可为 CC BY 4.0。273 个文件、约 758 MB，均按官方 SHA-256 校验。下载清单位于 `reproduction/manifests/dataset-manifest-v5.json`。

| 患者 | 23 | 23 |
| 切片 | 68 | 68 |
| 点 | 30,627 | 30,612 |

差异原因尚未完全确定。没有为凑齐论文数量而任意删点或补基因。每张切片统计保存在 `reproduction/reports/dataset-summary.json`。

文件依据 metadata.csv 中患者、分型和切片对应关系整理，处理 BC / BT 命名差异。坐标转为作者代码所需格式，肿瘤标记按原实现四舍五入匹配。逐切片预处理并通过磁盘暂存矩阵计算统计量，以控制内存占用。

JPEG 经 libvips 转为无损分块 TIFF。已抽检两个患者的 6 个点，表达计数与原矩阵一致，TIFF 图块与原 JPEG 解码像素一致，报告在 `reproduction/reports/data-integrity-check.json`。

数据已准备好，无需重复执行。需要重建时，在项目根目录激活环境后运行：

```bash
python reproduction/fetch_data.py
python reproduction/prepare_streaming.py
cd ST-Net
bash bin/create_tifs.sh
```

不要在同一处理目录混用不同数据子集的基因列表。移动整个项目后，需要修改 `ST-Net/stnet.cfg` 中的数据绝对路径。

## 训练管理与结果

后台管理入口为 `reproduction/first_experiment.py --simplified`，调用 `run_simplified.sh`。结束后自动运行 `evaluate.py` 评估第 50 轮；失败时在状态文件中记录错误。

```bash
# 查看当前状态和进度
cat output/simplified/status.json
tail -f output/simplified/train.log
```

若进程已经退出且需要恢复，在项目根目录运行：

```bash
source /home/mio/tools/miniconda3/etc/profile.d/conda.sh
conda activate STNet
python reproduction/first_experiment.py --simplified
```

训练脚本启用作者的 checkpoint 恢复逻辑，读取最近已保存轮次的模型与优化器状态。活动任务存在时后台管理入口会阻止重复启动。

训练期间曾保存每轮预测；整理后仅保留第 50 轮预测，checkpoint 为 `output/simplified/checkpoints/epoch_50.pt`。最终指标文件：

- `output/simplified/pred_50.summary.json`：RMSE、训练均值基线 RMSE、Pearson 汇总。
- `output/simplified/pred_50.metrics.csv`：逐基因 Pearson 和 RMSE。
- `output/simplified/pred_50.npz`：预测、真实表达、基因、患者与空间位置。

结果已生成，但单患者简化实验不能证明达到论文的完整指标。
