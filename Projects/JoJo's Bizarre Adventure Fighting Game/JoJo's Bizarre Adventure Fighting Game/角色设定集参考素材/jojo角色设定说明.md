# **角色背景**

角色原型

《JOJO》系列的作者陆曾提到，近藤胜太郎的原型是美国演员克林特·伊斯特伍德。荒木的父亲是伊斯特伍德的粉丝。荒木小学时在父亲的带领下观看了由伊斯特伍德主演的电影《黄金三护卫》。荒木对伊斯特伍德在这部电影中的表现印象深刻。从那以后，荒木开始追随伊斯特伍德的电影。对于荒木来说，伊斯特伍德是理想的英雄。

伊斯特伍德给了荒木塑造承太郎的灵感。在澄太郎可以看到许多伊斯特伍德的影子。受伊斯特伍德的影响，承的角色说话不多，也没有多余的动作。在战斗中，他还把手放在口袋里静静地站着，但他可以使用非常快速和毁灭性的攻击。

关于帽子

科塔·塞克塔罗最明显的特点是他的帽子和学生制服，这受到了《巴比伦II》中沙漠+学生制服形象的影响，以及《爱与真诚》等不良漫画的影响。当作家阎为程画帽子时，他决定把这顶帽子作为程的象征，即使程想潜入其中，阿拉基也不让他摘下帽子。

在画承太郎时，荒木认为“这是一个很好的选择，让每个人都困惑于承太郎头上的帽子在哪里”。荒木也认为在帽子和头发之间加一条白线会显得很土气，所以他决定把承太郎的帽子和他的头和头发结合起来。

# **性格特点**

空条承太郎认为没必要刻意将自己的感情表现出来，他认为大家应该都能看得出来。而这也导致承太郎很容易被人误解，周边的人都觉得他性格冷淡、反叛、对什么事情都不感兴趣。也正因如此，承太郎才会经常惹上麻烦。承太郎喜欢传统的日本女性，最讨厌吵闹的女人 。其口头禅为&[#34;真是够了&#](https://search.bilibili.com/all?keyword=34%3B真是够了%26&from_source=web_dynamic_tag&spm_id_from=333.1369.0.0)34;(やれやれだぜ) 。

# **获得替身**

1983年，迪奥·布兰度的棺材从海中被打捞起来。

1986年，DIO得到替身能力。

1986年，乔斯达家族受DIO影响不同程度地展示出替身能力。

1987年12月，空条承太郎由于不清楚事实真相误以为自己被幽灵缠上于是将自己关于监狱中以防伤害到其他人，被乔瑟夫·乔斯达和穆罕默德·阿布德尔逼出，开始正视自己的替身能力。阿布德尔用塔罗牌将其替身命名为白金之星。

在刚出场的时候，空条承太郎的身份是一名高中生，家庭富裕，身材高大，相貌英俊，因此他会承为学校女生们追求的偶像。同时，他性格冷静，头脑聪明，外冷内热，富有正义感，符合古典主义英雄形象。但由于年龄尚小，在诸多细节处表现出十足的少年感。

在星尘十字军的故事里，第一部中的反派迪奥·布兰度【DIO】苏醒后在恩雅婆婆的帮助下获得了替身能力。

由于迪奥·布兰度窃取了乔纳森·乔斯达的身体，身为乔纳森·乔斯达后代的空条承太郎、乔瑟夫·乔斯达以及空条贺莉的替身能力也得以觉醒。

# **石之海**

2011年11月，空条承太郎的女儿空条徐伦被迪奥·布兰度的挚友恩里克·普奇陷害入狱。为救女儿，承太郎计划劫狱，却没有料到恩里克·普奇本来的目标是得到承太郎记忆中所拥有的迪奥·布兰度&[#34;上天堂的秘密&#](https://search.bilibili.com/all?keyword=34%3B上天堂的秘密%26&from_source=web_dynamic_tag&spm_id_from=333.1369.0.0)34;，被恩里克·普奇偷袭抽出自身的记忆DISC与替身DISC，失去记忆和替身力量，成为生理上的植物人，在身体被SPW财团保存。其后空条徐伦夺回承太郎的DISC(记忆和替身力量)，使其复活。虽然承太郎在最终决战及时赶到，但是恩里克·普奇已经完承最后的进化，所有人都完全无法抗衡天堂制造的速度，安娜苏用生命换来了仅有的一次可以利用时间停止攻击神父的机会，然而正如神父所说，乔斯达家族的荣耀赋予了承太郎强大的力量，但也带来了人性所必然具备的弱点，承太郎由于本能地在暂停的时间内选择了先保护女儿而错失了杀死恩里克·普奇的机会，最终被其杀害，且被杀死的一行人的尸体受普奇能力影响高速腐坏消失。在此战中最后幸存的安波里欧·亚曼纽在一次轮回后打败恩里克·普奇之后进入了新世界。
