# 城市街道场景

素材使用内置 imagegen 生成，参考用户指定视频中的夜间开罗街道氛围。

## 素材与生成设计

- `backgrounds/city_street.png`：横向格斗游戏侧视像素街道。紫蓝夜空、远景穹顶与宣礼塔、暖黄色窗灯、砂岩楼房、阳台、拱门及连续石板街面。无角色、文字和 UI。画面用于 3200×1800 世界背景。
- `platforms/city_ledge_large.png`：透明背景的长砂岩外墙檐台。平直可站立的顶部、雕刻石块、支撑托架，暖色光照，与街道建筑一致。
- `platforms/city_ledge_small.png`：透明背景的短砂岩台阶，保持相同光照和建筑纹理。

运行时将平台的透明留白裁去，以最近邻缩放到 512px、288px 宽。生成原图保存在上述资源路径。

## 可调整位置

- `game_config.h`：窗口 1600×900，地图 3200×1800，街面碰撞高度 1540。
- `game_scene.h` 的 `on_enter()`：三条外墙路线，每级高度差 180px；中层台阶连接三条路线，街面连续可行走。
- `camera.h`：跟随双方角色，缩放范围 0.5–1；命中抖动在世界绘制时应用，血条固定。
- 角色数值仍从 `resources/character_stats.csv` 加载。修改 Excel 表后另存 CSV 时保留列顺序与参数键名，重启游戏生效。
